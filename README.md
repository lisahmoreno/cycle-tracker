# Cycle Tracker

A personal lifestyle diary app for tracking daily wellbeing, symptoms, and patterns over time.

**[Live Demo](https://cycle-tracker-phi.vercel.app)**

## Features

- Daily log entries with mood, energy, and symptom tracking
- Visual charts showing patterns over time
- PDF export of tracked data
- Fully client-side — no data leaves your browser

## Tech stack

- React + Vite
- Recharts for data visualisation
- date-fns for date handling
- pdf-lib for PDF export

## Run locally

```bash
npm install
npm run dev
```
